# Size Mod

Мод для Minecraft 1.20.1 на Forge, добавляющий три зелья для изменения размера игрока. Работает на базе [Pehkui](https://modrinth.com/mod/pehkui) — без него не запустится.

---

## Зелья

Все зелья варятся в варочной стойке на основе **неловкого зелья** (Awkward Potion).

| Зелье | Ингредиент | Эффект |
|---|---|---|
| Зелье уменьшения | Фрукт хора | Уменьшает игрока до 0.5x |
| Зелье увеличения | Золотая морковь | Увеличивает игрока до 2.0x |
| Зелье восстановления | Одуванчик | Возвращает стандартный размер |

Эффекты **постоянные** — не спадают сами по себе. Снять можно только выпив зелье восстановления. Если выпить зелье уменьшения, а потом увеличения — новый эффект перезапишет старый.

---

## Установка

1. Установи [Minecraft Forge 1.20.1](https://files.minecraftforge.net) (версия 47.2+)
2. Установи [Pehkui](https://modrinth.com/mod/pehkui) для 1.20.1
3. Скинь `sizemod-1.0.0.jar` в папку `mods/`
4. Запускай игру

---

## Требования

- Minecraft 1.20.1
- Forge 47.2+
- Pehkui 3.7+
- Java 17

---

## Сборка из исходников

Нужен JDK 17. В папке проекта:

```bash
gradlew build
```

Готовый `.jar` появится в `build/libs/`.

Зависимость Pehkui подтягивается через Modrinth Maven — интернет нужен при первой сборке.

---

## Как это работает

Мод использует `ScaleTypes.BASE` из Pehkui API для изменения базового масштаба сущности. Масштаб влияет на модель, хитбокс и физику игрока. Эффекты зелий реализованы как кастомные `MobEffect` — каждую секунду они обновляют масштаб через `ScaleData.setScale()`, пока активны.
